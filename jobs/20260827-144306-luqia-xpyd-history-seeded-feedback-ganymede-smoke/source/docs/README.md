# Repository documentation

This directory contains repository-level audits and planning material. Runtime,
experiment, and paper-specific documentation remains next to the implementation
under `paper/`.

- `RESEARCH_GAP_ANALYSIS.md`: current research positioning and implementation gap.
- `CODEBASE_AUDIT.md`: code/data audit, canonical artifact selection, and model provenance.
- `HANDOFF_FOR_CHATGPT.md`: detailed project handoff and reproduction notes.
- `GITHUB_UPLOAD_PLAN.md`: repository curation and external-artifact policy.
- `RelatedWorkComparison_updated_2026-08-17.md`: related-work comparison.
- `sweep_llm_issue_checklist.md`: historical sweep-LLM issue checklist.
- `sweep_llm_top_tier_review_and_trim_plan.md`: historical review and trimming plan.
